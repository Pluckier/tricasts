# 🏆 Tricast Analysis

A specialized tool for identifying high-value betting opportunities in large-field handicap races.

## 🎯 Selection Logic
Races are automatically flagged as Tricast-eligible based on two criteria:
- **Type**: Must be a Handicap race.
- **Field Size**: 8 or more runners (including Non-Runners).

## 🚀 Features
- **Live Badge Counting**: Real-time notification counters on the filter bar.
- **Tips Integration**: Seamlessly syncs with the symbol-driven heuristic engine.
